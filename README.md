#STAR NEXUS — game bắn phi thuyền vũ trụ "siêu khủng" (tổng assets + code vài MB) đã build thành công.

#Nội dung game:

Engine canvas 60FPS tự viết: vật lý, particle, screen shake, parallax sao, trail đạn.
6 vũ khí: Blaster, Spread, Laser xuyên, Tên lửa dò mục tiêu, Plasma, Railgun.
6 loại địch với AI khác nhau (dive, sine, chase, orbit, kamikaze, turret) + 5 BOSS khổng lồ (sprite AI 4K) với bullet-hell pattern: spiral, wall, aimed, burst, laser sweep, đổi phase theo máu.
Hệ thống RPG: XP/level-up chọn 3 thẻ ngẫu nhiên — 8 nâng cấp (dmg, rate, speed, shield, HP, drone, magnet, crit) + 6 perk (hút máu, phản đòn, nova, bẻ cong thời gian, quá tải, may mắn).
Vật phẩm rơi, bom màn hình (E), lướt né (Shift), combo nhân điểm, lưu kỷ lục localStorage.
Âm thanh WebAudio synth tự tạo (bắn, nổ, level-up, game over) + nút tắt tiếng.
4 ảnh nền/sprite AI độ phân giải cao, HUD đầy đủ, hỗ trợ chuột/phím/cảm ứng.
